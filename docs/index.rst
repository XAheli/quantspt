quantspt — Stochastic Portfolio Theory
======================================

**quantspt** is the definitive Python library for Stochastic Portfolio Theory,
implementing the complete mathematical apparatus of SPT as developed by
E. Robert Fernholz, Ioannis Karatzas, and collaborators.
